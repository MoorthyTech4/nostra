Nostra - Beginner eCommerce Website
Nostra is a beginner-friendly eCommerce website project built using HTML, CSS, and JavaScript. This project is designed to help beginners understand how to create a modern responsive online shopping website with clean structure and simple functionality.
Features
Responsive design for mobile, tablet, and desktop
Modern homepage with hero section
Collections page with product cards
Search products using JavaScript
Filter products by category
Mobile responsive navigation menu
Contact page with working form interaction
Clean and beginner-friendly code
Technologies Used
HTML5
CSS3
JavaScript
Purpose of This Project
This project was created for practice and learning front-end web development concepts such as layout design, responsive styling, DOM manipulation, events, search functionality, and filtering products.
Suitable For
Beginners learning web development
Students building portfolio projects
Practice for HTML CSS JavaScript concepts
